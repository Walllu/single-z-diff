# Calibration payloads

- `muon_momentum_2016H_bb_be_ee.json`: compact BB/BE/EE momentum scale and
  additional Gaussian-resolution parameters derived from the full locally
  available 2016H data and Z-to-muon simulation production.
- `experimental/pileup_nvertices_2016H_bb_be_ee.json`: reconstructed-vertex
  reweighting used by the exploratory validation and Energy Flow Gap workflow.
  It is not a replacement for a true-pileup calibration.

Derivation details and limitations are recorded in the reports alongside the
corresponding scripts.
